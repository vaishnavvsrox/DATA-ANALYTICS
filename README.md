👥 Human Resource Management System (HRMS) – Power BI

📌 Project Overview

The Human Resource Management System (HRMS) is a data analytics project developed using Microsoft Power BI to analyze employee information, departmental distribution, salary status, and employee performance.

The project focuses on transforming HR data into meaningful insights through relational data modelling, DAX calculations, and interactive dashboards.

🎯 Project Objectives

- Analyze overall employee distribution.
- Monitor employee performance across departments.
- Evaluate salary status using categorized salary levels.
- Understand departmental workforce distribution.
- Develop interactive dashboards for HR analytics.
- Enable detailed analysis through drill-down and drill-through functionality.

 🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and visualization
- Power Query – Data cleaning and transformation
- DAX – Measures and calculated columns
- Data Modelling – Relational data modelling and table relationships

 🗂️ Data Modelling

Developed a relational data model to organize employee information and supporting attributes.

Key relationship fields include:

- Department ID
- Performance ID
- Salary Status ID

The model connects employee information with relevant departmental, performance, and salary status data.
 🧹 Data Cleaning & Transformation

Performed data preparation using Power Query:

- Checked and handled missing values.
- Reviewed data consistency.
- Transformed columns into appropriate data types.
- Prepared tables for relational modelling.
- Organized categorical data for analysis.
